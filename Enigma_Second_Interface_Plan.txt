ENIGMA M3 - PLAN PENTRU A DOUA INTERFATA
======================================

Scop
----
O a doua prezentare a aceleiasi masini, accesibila din prima pagina prin
butonul "Mode". Interfata actuala ramane disponibila ca "Classic";
noua interfata este "Diagram". Comutarea este reversibila in aceeasi fereastra.

Referinta: Coding Cassowary, "Coding the Enigma machine - Part 1"
https://www.youtube.com/watch?v=sbm2dmkmqgQ
Capitolele publicate includ Keyboard, Plugboard, Rotors, Reflector si
Enciphering a letter. Descrierea si capitolele au fost consultate;
aspectul exact al cadrelor nu a fost verificat vizual. Compozitia de mai jos
este o propunere, de comparat cu un cadru ales din videoclip in etapa 01.

Branch propus: feature/12-diagram-interface
Baza: origin/develop actualizat, dupa integrarea etapei 11.
PR: feature/12-diagram-interface -> develop.
Branch creat: feature/12-diagram-interface din origin/develop.

Comportament
------------
- Bara comuna: titlu, Mode, modul activ si status.
- Mode comuta Classic <-> Diagram; ramane vizibil in ambele moduri.
- Se pastreaza mesajele, configuratia aplicata, pozitiile curente,
  istoricul Undo si setarile editate, inclusiv cele neaplicate.
- Schimbarea modului nu cripteaza, nu avanseaza rotoare si nu reseteaza.
- La comutare se opreste animatia vechii vederi si se elibereaza tastele
  retinute. Ultimul traseu poate fi reluat in noua vedere.
- Modul initial este Classic; memorarea preferintei intre porniri este optionala.

Aspect propus pentru Diagram
---------------------------
- Zona centrala larga cu reflector, trei rotoare, plugboard si intrare/iesire.
- Fiecare componenta are contacte A-Z, etichete si conexiuni vizibile.
- Cele doua sensuri ale semnalului au culori distincte si indicatoare de sens;
  explicatia textuala nu depinde exclusiv de culoare.
- Pozitiile rotoarelor si traseul literei urmeaza starea reala a motorului.
- Tastatura si lampboard raman disponibile sub diagrama.
- Mesajele si setarile sunt accesibile dintr-un panou lateral sau file.
- Play/Pause/Step si viteza controleaza doar redarea traseului.
- La fereastra mica: diagrama scalata cu litere lizibile sau scroll;
  comenzile Mode, Reset si criptarea raman accesibile.

Arhitectura
-----------
- Un singur MainController, EnigmaService si set de view models pe sesiune.
- App construieste un ApplicationShell cu bara Mode si continutul activ.
- MainView este vederea Classic; DiagramView este noua vedere.
- InterfaceMode descrie modul; shell-ul detine selectia si ciclul de viata.
- Un singur gestionar de input/scurtaturi instalat pe Scene.
  KeyboardView.attachTo adauga acum filtre si un listener pe Stage;
  acestea trebuie refactorizate cu dezabonare explicita sau mutate intr-un
  gestionar comun, pentru a preveni criptarea dubla dupa comutari.
- Vederile au activare/dezactivare: opresc Timeline, elimina listener-ele
  temporare si nu mai reactioneaza la input cand sunt ascunse.
- SignalTrace furnizeaza pasii reali de intrare/iesire si pozitiile dupa
  stepping. Pentru desenarea TUTUROR firelor unui rotor poate fi necesar
  un snapshot imutabil de mapping, calculat prin logica existenta a rotorului.
  Diagrama nu reimplementeaza formulele de criptare in JavaFX.
- Formele si firele se deseneaza cu noduri JavaFX; CSS separat,
  limitat prin clasa radacina a noii vederi.
